# トーナメント表作成

2〜16組の参加者から、勝ち上がり式トーナメント表を作成・記録するブラウザーツールです。

## 主な機能
- 2〜16組対応
- 参加者の入力順配置・ランダム配置
- 端数人数の不戦勝自動配置
- 勝者選択と次ラウンドへの自動進出
- 3位決定戦（任意）
- 結果のリセット・コピー
- 入力内容のブラウザー保存
- スマートフォン・タブレット・PC対応

## 公開
GitHubで `tournament-maker` というPublicリポジトリを作り、4ファイルをアップロードします。Settings → Pagesでmainブランチの `/ (root)` を公開します。
